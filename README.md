# CloudeCodeDefender

Консольный защитник вашей подписки VPN: убивает выбранный процесс, если VPN-адаптер отключается.

## 🎯 О проекте

- При отвале VPN игра/программа/ide продолжает работать и палит реальный IP.
- Данную программу посоветовал сделать мой друг и посовметительству начальник. 
- Она предназначена для защиты от сервисов блокирующих по IP-адресу пользователя.

## 📦 Установка

### Вариант 1 — готовый `.exe` (Release)

1. Скачай `CloudeCodeDefender.exe` из [Releases](../../releases).
2. Положи в любую папку.
3. Запусти двойным кликом или из терминала.

## 🚀 Использование

Пошагово:
1. Запусти программу.
3. Выбери **процесс**, который нужно убить при падении VPN.
4. Выбери **сетевой адаптер**, который является твоим VPN.
5. Программа начинает мониторинг (раз в секунду проверяет `OperationalStatus`).
6. Если адаптер ушёл в `Down` — процесс убивается, пишется лог, происходит возврат в меню.
